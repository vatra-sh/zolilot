# Zolilöt AG

Corporate site for a fictional Swiss soldering company (class inside joke). Next.js 16, Tailwind v4, Motion.

- All copy lives in `src/content.ts`; edit jokes there.
- `npm run dev` for development, `npm run build && npm start` for production.
- `scripts/prep-assets.py` and `scripts/prep-mark.py` turned the source images into `public/` assets.
- `noindex` is set on purpose: the hero shows a real person.
